Repeated Substring Pattern
https://leetcode.com/problems/repeated-substring-pattern/description/
Program:-
class Solution {
    public boolean repeatedSubstringPattern(String s) {
        String doubled = s + s;

        return doubled.substring(1, doubled.length() - 1).contains(s);
    }
}
